Este projeto é uma ferramenta digital para o jogo de tabuleiro Detetive. Ele foi criado para resolver um problema comum: a falta de uma opção digital eficiente para gerenciar as pistas e o progresso do jogo.

Uma das principais funcionalidades é o salvamento automático do estado do jogo no localStorage, garantindo que as informações não se percam ao atualizar a página ou fechar o navegador. 

Ele representa o meu primeiro passo no mundo da programação e do desenvolvimento de software, sendo uma jornada de aprendizado e aplicação de conceitos essenciais de desenvolvimento web pensado em mobile first e responsividade.
